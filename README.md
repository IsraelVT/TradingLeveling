# Trading Leveling — MVP 0.1

Prototype of the first five interactive missions.

## Run locally
Requires Node.js 20.19+ (or a compatible current Node release).

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build
```bash
npm run build
```

This version intentionally uses controlled scenarios and local React state. Historical market data, authentication, backend persistence, real replay, and AI coaching come later.
